<h1 align="center"> Sistema de Reservas </h1>

Este repositório contém a implementação de um sistema de reservas, desenvolvido com foco em boas práticas de API REST utilizando Node.js v18. O sistema permite realizar operações de CRUD relacionadas a reservas, como criação, listagem, atualização e remoção de reservas. Além disso, possui testes automatizados para garantir o bom funcionamento da aplicação.
<br>

## 📥 Requisitos <a name="Requisitos"></a>

1. Instalar o [Node.js v18](https://nodejs.org/en/download/).
2. Um editor de código como o [Visual Studio Code](https://code.visualstudio.com/) (opcional, mas recomendado).
   <br>

## 🧩 Como executar <a name="Como-executar"></a>

1.  Clone o repositório em sua máquina usando o terminal Git Bash ou outro terminal de sua preferência:

    ```
    git clone https://github.com/IagoCB/fc4-tdd.git
    ```

    ou via SSH:

    ```
    git clone git@github.com:IagoCB/fc4-tdd.git
    ```

2.  Acesse o diretório do projeto:

    ```
    cd fc4-tdd
    ```

3.  Instale as dependências do projeto:

    ```
    npm i
    ```

4.  Para executar os testes automatizados:

    ```
    npm test
    ```
